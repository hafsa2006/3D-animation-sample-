# 3D Animation Sample

A modern 3D animation showcase website designed to demonstrate premium web experiences through cinematic visuals, immersive motion, and interactive design.

## Features

- 🎨 Modern UI/UX Design
- ✨ Glassmorphism Components
- 🎬 Cinematic Motion Effects
- 🚀 Framer Motion Animations
- 🌐 Three.js & React Three Fiber Integration
- ⚡ GSAP-Powered Interactions
- 📱 Fully Responsive Layout
- 🎭 Interactive 3D Elements
- 🌙 Premium Dark Theme
- 🔥 Built with React + Vite + Tailwind CSS v4

## Tech Stack

- React
- Vite
- Tailwind CSS v4
- Framer Motion
- GSAP
- Three.js
- React Three Fiber
- Lucide Icons

## Goal

This project explores award-winning web design principles inspired by modern interactive experiences, combining 3D graphics, motion design, and storytelling to create an engaging digital showcase.
